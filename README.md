# GB Life of Pi 🐯

An informative website about Yann Martel's *Life of Pi* — exploring the novel's story, characters, themes, and the journey of Pi Patel across the Pacific Ocean.

---

## Project Structure

```
GB_Life_of_Pi/
├── frontend/          # React + Vite frontend
│   ├── src/
│   │   ├── components/    # Navbar, Hero, About, Characters, Themes, Gallery, Footer
│   │   ├── App.jsx
│   │   ├── App.css
│   │   └── main.jsx
│   ├── index.html
│   ├── vite.config.js
│   └── package.json
└── README.md
```

> **Backend-ready**: When you add a backend (Node/Express, Django, etc.), create a `backend/` folder at the root alongside `frontend/`.

---

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

The dev server runs at **http://localhost:5173**

### Build for Production

```bash
cd frontend
npm run build
```

## Pages / Sections

- **Hero** — Cinematic landing with animated ocean waves
- **About** — Book overview and key stats
- **Characters** — Interactive character profiles (Pi, Richard Parker, etc.)
- **Themes** — Major literary themes explored in the novel
- **Timeline** — Pi's journey from Pondicherry to Mexico
